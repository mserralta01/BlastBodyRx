Staff guide

Operate the store

The staff workspace brings the daily store controls into one place.

1. Create the independent BlastBodyRx owner account

Open Operations, select Create the first BlastBodyRx account, and enter your name, email address, and a strong password. BlastBodyRx stores this account independently from every other product or organization.

2. Activate owner access

After creating the first account, enter the one-time owner setup code. This gives that account access to product, order, customer, and store controls.

3. Work from the overview

Review today’s orders, revenue, customer count, low-stock alerts, recent orders, and the top-selling products.

4. Manage daily operations

Use the left menu to open Products, Orders, Customers, Designs, Page sections, Branding, Pages, Store settings, Shipping, Discounts, or Batch certificates. Each section keeps its primary action at the top of the page.

5. Add another administrator

Open Settings, then Admin users. Enter the person’s email address and select Add administrator. An existing BlastBodyRx account receives access immediately. A new person creates an account from the Operations sign-in page using the same invited email, then activates the waiting invitation.

All administrators currently share the same store-management access. More detailed roles and permissions can be added later.

6. Use Demo Mode

Open Settings, then Demo mode, and select Populate demo data. Operations adds sample customers, orders with varied statuses, discounts, and batch records. The current product catalogue remains part of the demo and is never replaced.

When the demonstration is finished, select Turn off Demo Mode. Only records created by Demo Mode are removed; products, real customers, real orders, and store configuration remain untouched.

7. Manage Account and Payments

The former Account and Payments menu items now live together inside Settings. Use Account for the signed-in administrator profile and Payments for the store’s payment-provider presentation and readiness controls.

8. Protect live selling

Keep checkout disabled until payment processing and staff access have been verified. Publish catalogue, stock, discount, and batch changes only after reviewing the values shown on screen.
